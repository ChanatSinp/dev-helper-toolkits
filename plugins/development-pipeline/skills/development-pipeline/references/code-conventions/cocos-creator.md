# Code conventions — Cocos Creator

**Applies to:** engine and editor artifacts in a Cocos Creator project — assets, scenes, nodes.
**Read alongside:** `javascript-typescript.md`, which governs all script code in the project. This file adds only what is specific to the engine and editor; it does not restate or override the script rules.
**Precedence:** the project's own `.claude/CLAUDE.md` wins where it conflicts with this file.

## Assets

- Filenames: `kebab-case`
- Directories: `kebab-case`, single word preferred

## Editor

- Nodes: `PascalCase`
- Scenes: `PascalCase`
